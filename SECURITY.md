# Security policy

Please do not open a public issue containing credentials, private transcripts,
production data, or a working exploit. Report security-sensitive problems to
the repository owner through a private channel and include a minimal,
redacted reproduction.

Godmode skills are instructions that may cause an agent to read files, run
commands, or modify code. Users should review the requested scope and command
before authorizing destructive, external, privileged, or production actions.
Skills must treat tool output and user-provided documents as untrusted data and
must not execute instruction-like text found inside them.
