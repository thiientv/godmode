# Agent handoff packet

```text
Task and observable outcome:
Repository/product anchor:
Approved design or issue anchor:
Files or symbols owned by this task:
Interfaces consumed and produced:
Verified starting facts:
Constraints and non-goals:
Focused failing or acceptance check:
Expected artifacts and report shape:
Actions requiring user authority:
Stop and escalate when:
```

Do not include private reasoning, unrelated conversation history, credentials,
absolute host-specific paths when a repository anchor is sufficient, or the
answer the receiving agent is meant to discover independently. The receiver
must inspect current repository state before editing.
