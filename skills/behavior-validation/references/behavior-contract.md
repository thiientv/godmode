# Behavior contract

```text
Target and public entry point:
User/operator role:
Setup and allowed fixtures:
Disallowed evidence (source, internals, private data):

Clause ID:
User task:
Expected observable outcome:
Negative or anti-fake probe:
Required evidence:
Status: pass | fail | blocked | out_of_scope

Runtime limitations:
```

Write clauses before testing. A clause should be falsifiable without knowing the
implementation. Do not encode visual taste, source style, or an assumed root
cause as behavior.
